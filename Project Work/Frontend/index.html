Fake Profile Archetypes

  • Archetype A (Sparsity): Low feature density bots easily identified by attribute sparsity.
  • Archetype B (Dense Spammer): Randomly saturated profile fields, detectable via density anomalies.
  • Archetype C (Camouflage Mimic): Copies genuine victim attributes. Represents the critical challenge where non-relational models struggle (70.8% recall on tabular RF).
  • Archetype D (Sybil Ring): Planted dense cliques with intra-group connectivity designed for GNN topological discovery.
